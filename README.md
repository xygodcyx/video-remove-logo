# Logo Eraser

一个可以直接双击打开、完全在浏览器本地运行的视频去水印 / 去 Logo 工具。

## 运行

1. 双击 `index.html`。
2. 推荐使用最新版 Chrome 或 Edge。
3. 选择视频，按页面步骤操作。

不需要安装依赖、不需要启动本地服务器，也不会把视频上传到任何地方。所有第三方库都已内嵌在这个 HTML 文件里。

## 操作流程

1. **导入与拆帧**：浏览器本地解码视频，并按时间顺序保存所有分析帧。长视频会均匀跳帧以控制内存。
2. **选择参考帧**：从整段视频中分层随机挑选 3–6 帧，用户选择其中一帧作为最终参考帧。
3. **框选 Logo**：在参考帧上框选 Logo。工具记录 Logo 区域、尺寸和图像内容。
4. **轨迹定位**：按用户设置的间隔（默认每 6 帧）抽取关键帧，通过边缘结构模板匹配找出每帧 Logo 的位置；低置信度结果会被剔除，其余位置用平滑曲线补间到每一帧。
5. **修复**：
   - 优先从其他时间点中 Logo 曾经离开的位置取回真实背景像素。
   - 如果存在多个可用的干净帧，会比较 Logo 周围背景，选择最接近当前帧的来源；不再混用多个部分遮挡帧，避免拼出明显色块。
   - 无法跨帧取回的区域，使用内容感知修补 + 平滑先验生成。
   - 修复区域会向外扩展 16px，并用 smootherstep 羽化与原画面做像素级融合，大幅减弱 Logo 矩形边缘的硬边。
6. **导出**：重新编码为 MP4（H.264）或 WebM（VP9），并在浏览器支持时保留音轨。

## 历史记录

- 成功导出视频后，页面会把**文件信息、Logo 选框、逐帧轨迹和处理参数**记录到当前浏览器的 `localStorage`。
- **不会缓存原视频、视频帧或导出的成品文件**，所以历史记录只占用很少空间。
- 在顶部点击「历史」即可查看。点击「恢复处理」需要重新选择同一个原视频文件（浏览器安全限制不允许自动读取本地路径），选中后会自动拆帧、恢复轨迹，并回到修复导出页。
- 历史记录只保存在当前浏览器；清理浏览器站点数据会同时删除它们。

## 数据与调试

开发者控制台里可以直接查看两个核心数据：

```js
LogoEraserDebug.all_logo_rects
LogoEraserDebug.all_restore_logo_rects
```

- `all_logo_rects`：逐帧 Logo 位置、尺寸、来源（检测 / 插值 / 锚点）。
- `all_restore_logo_rects`：逐帧修复记录，包括窗口、跨帧来源和使用的干净像素量。

## 限制与建议

这是一个**单文件、零服务器、经典计算机视觉**实现，不是生成式 AI 去水印模型。

- **移动的 Logo 效果最好**：背景会随着 Logo 移动暴露出来，跨帧取回的像素能较完整地还原背景。
- **静止 Logo 更困难**：如果 Logo 固定不动，被它遮住的背景在整段视频里从未出现过，只能靠空间修补推测。16px 羽化能减弱明显的矩形硬边，但大面积、复杂纹理的静止 Logo 仍可能留下模糊或纹理不一致的痕迹。
- **背景运动**：跨帧取回假设相机/背景在相近位置基本一致。强烈运镜、背景中的人或物体移动可能造成接缝或残影。
- **只支持矩形选区**：选区应尽量贴近 Logo。修复时会在四周额外扩展 20px，其中外圈 16px 用于与周围画面羽化融合。
- **固定尺寸跟踪**：默认 Logo 在视频中大小不变。Logo 发生缩放时可能需要重新选择参考帧。
- **多线程**：页面会通过 `navigator.hardwareConcurrency` 检测逻辑 CPU 核心数，并为每个逻辑核心启动一个 Worker（上限 32 个），并行处理拆帧编码、模板匹配和空间修补。
- **长视频**：浏览器内存有限，单次最多分析 2400 帧；超出时会均匀跳帧并降低输出帧率。建议对长视频先剪辑出需要处理的部分。
- **导出依赖 WebCodecs**：Chrome/Edge 支持最好。MP4 的 H.264 音轨通常直接复制源文件 AAC 音轨；如果浏览器没有 AAC 编码器，可以改用 WebM 保留声音。
- **手机竖屏视频**：自动读取视频旋转元数据，修复后输出为正向画面。
- **历史记录不包含成品**：只记录参数与轨迹；重新处理时必须重新选择原视频，无法从历史中直接下载上一次导出的文件。

## 技术信息

- 解码：HTMLVideoElement 备用解码 + MP4Box.js 解析 MP4 + WebCodecs `VideoDecoder`
- 跟踪：多尺度灰度边缘图上的归一化互相关（NCC），并做连续性过滤
- 补间：PCHIP 单调三次插值（或线性）
- 修复：跨帧像素采样 + 内容感知块修补 + 16px 羽化融合
- 多线程：`navigator.hardwareConcurrency` → Worker 池；拆帧编码 / 模板匹配 / 空间修补并行执行
- 导出：WebCodecs `VideoEncoder` + mp4-muxer / webm-muxer
- 音轨：AAC 原始样本直通复用，或 WebCodecs `AudioEncoder` 转码（AAC/Opus）
