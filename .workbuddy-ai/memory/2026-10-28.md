## v1.5：多参考帧"先对齐再平均" + 手动轨迹（2026-10-28 下午）
用户反馈"多参考帧效果还不如单帧，框和我的坐标对不上"。定位到两个真 bug：

### 1) 集成模板未对齐就平均（根因）
- 模板是 Sobel 边缘图；手画框帧间差 4px，`corr` 从 0.70 掉到 **0.17** → 低于 0.20 门限，6 帧只剩 2 帧进集成（等于单帧）；侥幸过门限的是错位裁剪，平均后模板变糊、NCC 峰值变平，跟踪更差。
- 修复：`alignRefToAnchor()` 在 scale=4 层用 anchor 模板滑窗对齐，再 `refineCandidate` 回 0 层；随后一律用 **anchor 的 w/h** 裁剪，并加 `t.length === anchorLen` 过滤（`集成 N` 不虚报）。
- 实测：±4px 手画框 → `corr 0.67/0.73/0.78`、`集成 4`，与像素级精确框完全一致。

### 2) 文字手动点被"通用微调"拖走
- `refineTextRect` 原来允许 ±14px / 0.75–1.25 倍尺度搜索，淡色水印上会把好框拖到邻近边缘。
- 修复：新增 strict 模式（手动点 ±4px、0.90–1.10 倍、惩罚 0.02/px 与 0.9）；`textRestoreFrame` 传 `{strict: !!coarse.manual}`。
- 实测 Logo-Text.mp4 框 `468,398,112,42`：#1775/#1790/#1800/#1810 偏移 `-2/+0/+0/+2`，`textPixels` 2471–2865。

### 4) 文字关键帧自动补间（v1.5 续）
- `textGapIsJump(a,b)`：`span<=2 && dist>12` 或 `speed>6` 或 `dist>60 && span<12` → 判为跳切（切景/瞬移），用 hold；否则线性补间。
- `applyManualTextKeyframes()` 预算 `gapLinear[]`（auto/hold/linear 三档），补间帧标 `interpolated:true`，轨迹 `source` 为 `interpolated`。
- UI `#textInterpSel`（关键帧之间：auto/hold/linear），`renderTrackPreview` 标「补间位置」。

### 5) 像素重建：alpha un-blend（v1.5 续）
- 半透明文字遮罩模型 `obs = (1-a)bg + a*ink`；在参考帧用扩散 bg 一次性解出每像素 `a`（clamp 0..0.92），目标帧反向 `bg = (obs - a*ink)/(1-a)`。
- 合成 ground-truth 测试 `synth.mjs`：合成白文字叠到已知干净背景上，跑真实管线测 PSNR。基线：水印帧 18.33 dB → 重建 28.75 dB（MAE 9.3）。
- alpha 估计器对比：per-pixel 扩散 bg（28.75）最优；global alpha 19.57；5×5 median 22.42。说明文字反走样/软渐变是真实的逐像素 alpha，不能全局化。
- mixing 模式 A/B：`direct`（纯 un-blend，0% diffusion low-freq）29.82、`half` 29.73、`hf`（高频叠加）29.37。`direct` 略胜；默认仍用 `hf`（更鲁棒，对付 alpha 噪声）。
- 关键 bug 修复：`ubOk` 门控后 `ubR` 在笔画外为 0 → 6px blur 拖向 0 → `hf` 加成大偏置（18.79 dB）。修复：blur 源数组在 `!ubOk` 处用 `diffused` 填充（低频即扩散值），只对 `ubOk` 像素施加高频叠加。opaque（a>=0.88）像素回退到合成填充而非 obs，避免把水印残留写回。
- 重要：该片为**多段拼接**，段内水印静止、段间位置变化，背景非全局静态 → **时间捐赠器不可行**，只能空间重建 + un-blend。
- 调试旋钮：`state.ubMix` = `'hf'|'direct'|'half'`（测试用，默认 hf）。
